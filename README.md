# GamePulse

Universal game news tracker covering **AAA**, **Indie**, **Mobile**, **Esports**, and the entire **Roblox** universe.

## Features

- Live-style news feed across all platforms
- **Roblox Daily Hub** with top experiences + daily/weekly event calendar
- Individual game tracking pages (`track.html?game=slug`) — open many in browser tabs
- Full searchable catalog (150+ popular titles)
- "Track This" + shared tracked list via localStorage
- Dark modern UI

## How to use

1. Open `index.html` in any browser
2. Browse the Roblox section or go to **Full Catalog**
3. Click any game → opens its tracker in a new tab
4. Pin games with **+ Track This**

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Main hub + Roblox Daily + Calendar |
| `track.html` | Individual game tracker |
| `catalog.html` | Searchable full catalog |

## Note on coverage

There are millions of games and Roblox experiences. This site prioritizes the most played / trending titles so you can track what matters.

Built with plain HTML + Tailwind CDN. No build step required.
